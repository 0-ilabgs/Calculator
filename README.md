🧮 Calculator

A simple and clean Calculator Web App built using HTML, CSS, and JavaScript.

This project is created as a beginner-friendly JavaScript project to practice DOM manipulation, button events, and basic calculator operations.

✨ Features
➕ Addition
➖ Subtraction
✖️ Multiplication
➗ Division
% Percentage
AC — Clear the complete input
DEL — Delete the last character
00 and 0 buttons
Decimal number support
Interactive calculator buttons
Clean and responsive-looking UI
🛠️ Technologies Used
HTML5 — Structure of the calculator
CSS3 — Styling and layout
JavaScript — Calculator functionality
Poppins Font — Used for the interface
📂 Project Structure
Calculator/
│
├── index.html
├── style.css
├── script.js
└── README.md
🎨 UI

The calculator has a dark-themed interface with rounded buttons, a large display area, and hover effects for better interaction.

🚀 How to Run
Clone the repository:
git clone https://github.com/0-ilabgs/Calculator.git
Open the project folder:
cd Calculator
Open index.html in your browser.

That's it! 🎉
